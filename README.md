# Prabeen's Portfolio

Welcome to my portfolio! This site showcases my projects, research, and skills as a Computer Science student. I built it using React and Vite to have a clean, fast, and responsive place to share my work.

## What's Inside

*   **About Me**: A little bit about who I am and what I do.
*   **Projects**: A collection of full-stack apps, tools, and games I've built.
*   **Research**: Details on my academic research in VR, Machine Learning, and Cognitive Science.
*   **Experience**: My professional journey and education history.

## Tech Stack

*   **Frontend**: React, CSS Modules
*   **Backend**: Express
*   **Database**: MongoDB
*   **Build Tool**: Vite
*   **Deployment**: GitHub Pages

## Running Locally

If you want to poke around the code:

1.  Clone the repo:
    ```bash
    git clone https://github.com/prabeen6260/portfolio.git
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Start the dev server:
    ```bash
    npm run dev
    ```

Feel free to check out the live version at [prabeen6260.github.io](https://prabeen6260.github.io/). Thanks for visiting!
